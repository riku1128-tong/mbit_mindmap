# MBTI相性マップ

メンバーの名前とMBTIを入力すると、お互いの相性をマインドマップで可視化するブラウザツールです。

**公開ページ:** https://riku1128-tong.github.io/mbit_mindmap/

## できること

- 名前とタイプを追加。5文字目のA（自己主張型）/T（慎重型）は任意です（「名前 INFJ-A」の形でまとめて貼り付けることもできます。最大40人）
- **全体マップ**：相性の良い2人ほど近くに配置。線の色と太さが相性の強さ、点線は「要歩み寄り」
- **その人中心のマップ**：丸をクリックすると、その人を中心に全員が枝で広がる。中心に近いほど相性が良い
- **マウスオーバー**：相性がいいところ、ぶつかりやすいところ、気をつけることをツールチップで表示
- **ペアの詳細・チームの概要**：4つの指標ごとの内訳、ベストの組み合わせ、タイプの分布

- **複数チーム**：「開発部」「サークル」など名前を付けて保存し、切り替えられます（30チームまで）
- **チーム間の移動・コピー**：メンバー詳細パネルから、タグなども含めて別のチームへ移動・コピーできます
- **タグと絞り込み**：メンバーにタグ（例: 営業、新人）を付け、タグごとにマップ・相性表・概要を表示できます。まとめて貼り付けでは `たかし INTJ-A #営業` のように書けます
- **検索**：名前・タイプ・タグで検索すると、該当する人がマップと相性表でハイライトされます
- **相性表（ヒートマップ）**：全員×全員のスコアを色の濃さで一覧にします。登録順／タイプ順で並べ替えられます
- **チームの傾向**：4つの指標やA/Tが7割以上偏っている、あるいは4グループのどれかがいないときに、気をつけることを表示します
- **班分けの提案**：班の数を選ぶと、班の中の相性の合計がなるべく高くなる分け方を提案します。結果は「1班」「2班」…のタグとして保存できます
- **共有リンク**：チームの中身をURLに埋め込んだリンクを作れます。開いた人の画面には新しいチームとして追加されます（データはURLの中だけにあり、サーバーには送られません）
- **書き出し・読み込み**：全チームをJSONで、選んでいるチームをCSVで書き出せます。どちらも読み込みできます
- **画像で保存**：いま表示しているマップを、チーム名・日付・凡例入りのPNGで保存します

入力したメンバーは、使っているブラウザの localStorage にだけ保存されます。

## 相性スコアの出し方

基準点50に、指標ごとの組み合わせで加点・減点します（45〜100点。100点を超えた分は切り捨て）。

| 指標 | 同じ | 違う |
| --- | --- | --- |
| N/S（ものの見方） | +20 | −10 |
| E/I（エネルギーの向き） | +3 | +10 |
| T/F（判断のしかた） | +8 | +2 |
| J/P（物事の進め方） | 0 | +10 |
| A/T（ストレスへの反応） | A同士 +3 / T同士 0 | +5 |

A/Tは、2人とも入力されているときだけ計算に入ります。

88点以上が「最高」、75点以上が「良好」、58点以上が「ふつう」、それ未満が「要歩み寄り」です。
よく言われる相性の考え方を点数にした目安で、科学的な根拠があるものではありません。

## ローカルで動かす

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。
