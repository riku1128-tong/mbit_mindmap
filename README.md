# MBTI相性マップ

メンバーの名前とMBTIを入力すると、お互いの相性をマインドマップで可視化するブラウザツールです。

**公開ページ:** https://riku1128-tong.github.io/mbit_mindmap/

## できること

- 名前とタイプを追加（「名前 INFJ」の形でまとめて貼り付けることもできます。最大20人）
- **全体マップ**：相性の良い2人ほど近くに配置。線の色と太さが相性の強さ、点線は「要歩み寄り」
- **その人中心のマップ**：丸をクリックすると、その人を中心に全員が枝で広がる。中心に近いほど相性が良い
- **マウスオーバー**：相性がいいところ、ぶつかりやすいところ、気をつけることをツールチップで表示
- **ペアの詳細・チームの概要**：4つの指標ごとの内訳、ベストの組み合わせ、タイプの分布

入力したメンバーは、使っているブラウザの localStorage にだけ保存されます。

## 相性スコアの出し方

基準点50に、4つの指標の組み合わせで加点・減点します（45〜98点）。

| 指標 | 同じ | 違う |
| --- | --- | --- |
| N/S（ものの見方） | +20 | −10 |
| E/I（エネルギーの向き） | +3 | +10 |
| T/F（判断のしかた） | +8 | +2 |
| J/P（物事の進め方） | 0 | +10 |

88点以上が「最高」、75点以上が「良好」、58点以上が「ふつう」、それ未満が「要歩み寄り」です。
よく言われる相性の考え方を点数にした目安で、科学的な根拠があるものではありません。

## ローカルで動かす

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。
